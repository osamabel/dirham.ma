# dirham.ma

Domain-for-sale landing page for [dirham.ma](https://dirham.ma/).

## Local development

```bash
npm install
npm run dev
```

## Deploy to Vercel

1. Push this repo to GitHub.
2. Import the project in [Vercel](https://vercel.com/new).
3. Deploy (Next.js is detected automatically).
4. In the project **Settings → Domains**, add `dirham.ma` and `www.dirham.ma`.
5. At your domain registrar, point DNS to Vercel as shown in the Vercel domains UI.

## Contact form

Offers are emailed to `belkhadirdev@gmail.com` via [FormSubmit](https://formsubmit.co).

The **first** form submission sends a confirmation email — open it and activate the form once. After that, offers arrive normally.
